# はり師きゅう師 解剖学・生理学ポータル

はり師・きゅう師 国家試験の **解剖学・生理学** の過去問を、回別・分野別・ランダムで練習できる静的サイトです（基礎の復習と過去問演習用）。
4択クイズ（10・30・50問）、学習ゲーム（コイン・ガチャ・おみくじ）つき。登録不要・記録は端末内（localStorage）のみ。

- 公開: https://nekomarugt.github.io/hari-kyu-portal/
- 収録: 解剖学 515問・生理学 455問（第1〜34回、欠番なし）。分野別は出題基準（2026年版）の大項目（解剖 A1〜A11／生理 P1〜P16）、中項目をサブ分野に使用。
- **複数正解の問題（12問: 解剖 3-24, 7-25, 8-31, 9-33, 13-25／生理 2-48, 3-41, 10-47, 11-42, 15-31, 23-31, 25-30）**: 単一選択で、正解の選択肢のうち**どれか1つ**を選べば正解（「※正解は複数あります。どれか1つを選んで」と表示）。解答後は正解の選択肢をすべて表示。データの `answers` は正解の選択肢すべて、`note` は上記の注意書き。
- 学習資料（`guide/`）: 解剖学 131項目・生理学 125項目（うち48項目を新規に書き起こし：神経系・免疫・痛覚・循環調節ほか）を出題基準（2026年版）の順に整理。各項目に「出題N問」「出題回」「頻出」を表示し、過去問へ、過去問から項目へ行き来できます（対応は自動割り当ての目安）。出題基準との対応表は `guide/coverage/`。まだ足りない内容は「準備中」と表示。
- 問題ごとの解説は準備中（画面では非表示）。
- 出典: 問題は公益財団法人東洋療法研修試験財団の国家試験問題を元にしています。

## 構成
- `anatomy/` `physiology/` … 過去問アプリ（`questions.json` `fields.json`）
- `guide/` … 学習資料（`anatomy/` `physiology/` の `content.js` ＝本文、`qlinks.json` ＝過去問⇄項目の対応、`coverage.js` ＝出題基準との対応表、図は webp/svg に圧縮済み）
- `quiz/` … 4択クイズ　`game/` … ゲーム本体　`gacha/` … ガチャ・おみくじ
- `sw.js` `manifest.webmanifest` … PWA（スコープ `/hari-kyu-portal/`、キャッシュ接頭辞 `hkp-`、保存キー `jkp-hk-game-v1`）
- `tools/gen_guide_pages.py` … 学習資料のHTMLを生成
- `tools/build_data.py` … 入力データから `questions.json` / `fields.json` を生成
